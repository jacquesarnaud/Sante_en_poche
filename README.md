# 🩺 Santé en Poche

## 📌 Description

Santé en Poche est une plateforme web innovante conçue pour faciliter l’accès aux services de santé en Côte d’Ivoire.
Elle permet aux utilisateurs de trouver rapidement des centres médicaux, des pharmacies de garde, et d’interagir avec un médecin virtuel pour des conseils rapides.

# 🎯 Objectifs du projet

### Faciliter l’accès aux soins de santé
### Réduire les pertes de temps dans la recherche de services médicaux
### Digitaliser les services de santé locaux
### Offrir une assistance médicale rapide grâce à l’IA

# 🚀 Fonctionnalités principales

### Recherche de centres médicaux proches
### Localisation des pharmacies de garde
### Consultation avec un médecin virtuel (IA)
### Géolocalisation des services de santé
### Interface simple et intuitive
